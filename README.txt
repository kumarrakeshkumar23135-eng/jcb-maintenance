JCB Maintenance website
========================
Files:
- index.html: main website + Netlify Forms customer request form
- success.html: confirmation page
- styles.css: professional responsive styling

Netlify:
1. Upload this ZIP to Netlify.
2. Deploy the site.
3. Open Netlify dashboard -> Forms to see customer submissions.
4. You can configure email notifications for new form submissions in Netlify.
5. Before publishing, replace the placeholder service location and sample images with your own business photos if desired.

Important:
- The form collects customer name, phone, email, location, machine details, problem description, priority and an optional problem photo.
- Do not collect unnecessary sensitive information.
- The site includes an independent-service disclaimer because "JCB" is a trademark; only claim official authorization if the business is actually authorized.
